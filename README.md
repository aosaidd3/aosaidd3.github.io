## 📖 项目简介 (Project Background)

在信息碎片化与同质化严重的时代，年轻人越来越难找到兼具“内容深度”与“真实社交”的纯净空间。**91社** 顺应这一需求而生，旨在通过去中心化的内容推荐机制与高度包容的社区氛围，为青年群体建立一个高品质的文化精神家园。

无论你是亚文化爱好者、科技极客、艺术创作者，还是单纯希望找人分享生活点滴的日常打工人，91社都能为你提供展示自我、交流碰撞的舞台。

## ✨ 核心特性 (Key Features)

### 1. 潮流文化与多元内容聚合
* **多维话题矩阵**：覆盖潮流艺术、数码科技、ACGN 圈层、都市生活方式、职场心得等数十种多元主题。
* **高质内容创作**：鼓励原创新鲜观点，拒绝无效搬运，让每次刷动态都能有所收获。

### 2. 沉浸式互动与社群体验
* **实时观点碰撞**：支持丰富的动态发布、弹幕互动与实时讨论区，让交流更加零距离。
* **圈层搭子匹配**：基于共同兴趣与文化标签，帮你快速锁定与你频率相同的伙伴。

### 3. 现代化极简 UI & 多端响应
* **极致视觉设计**：采用符合年轻人审美的现代极简界面与夜间模式，长读不累眼。
* **全端无缝适配**：全面兼容 Mobile / Tablet / PC 端，随时随地开启文化探索体验。
